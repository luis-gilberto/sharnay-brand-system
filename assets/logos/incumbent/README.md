# Incumbent mark

Sharnay Photography's mark as it stood at the start of the engagement, July 2026.

**This is not an LG Studio deliverable and must never be sent as one.** It is here as reference, not as output. The rule in the parent folder still holds: nothing enters `assets/logos/` itself before final approval.

---

## What it is

A horizontal lockup. A gold aperture mark set left of "Sharnay" in a high contrast serif, with "Photography" in a light sans beneath, letterspaced to the width of the word above it.

| File | Size | Notes |
| --- | --- | --- |
| `sharnay-lockup-horizontal-black.png` | 380 × 181 | As supplied. Transparent, and 83% of the canvas is empty |
| `sharnay-lockup-horizontal-black-trimmed.png` | 351 × 102 | Cropped to the ink, so spacing is set in layout rather than baked into the file |

Supplied as a single PNG described as a 2x footer asset. The trimmed version is what `reading-the-practice` uses, since the original carries 42px of padding above the mark and 37px below, which fights any attempt to set it against type.

## Why it is kept

Three reasons, all of which will matter later.

It is the baseline. Any new mark will be judged against this one, and the comparison is worth being able to make honestly rather than from memory.

It is the subject of a question. Chapter VI of the intake asks what already exists and what is already printed. This is the answer to part of it, and the intake asks her for photographs of everything else.

It is evidence. What the previous mark got right is as useful as what it got wrong, and a redesign that cannot say which is which is guessing.

## What is missing

**A reversed or white version.** The supplied file is black, which works on paper and fails on any dark ground. The intake needed a light variant for its photographic screens and did not get one, so the mark appears only on the two paper documents there.

**A vector.** 351px of ink is enough for roughly 175px on screen and nothing more. It is visibly soft in print. An SVG, PDF, or EPS would remove the ceiling.

**Every other lockup.** Stacked, monogram, and icon-only versions, if they exist. Ask before assuming they do not.
