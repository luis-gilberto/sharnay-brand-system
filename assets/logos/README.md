# Logos

Distributable mark files. The versions that leave the studio.

Opens in **Phase 2**, once the mark is approved. Currently holds no approved work.

One exception sits alongside it. [`incumbent/`](incumbent/README.md) holds Sharnay Photography's existing mark, kept as reference for what the engagement is replacing. It is filed here because that is where anyone looking for a Sharnay logo will look, and it is labelled as plainly as possible so it is never mistaken for output.

---

**Holds** — every approved mark, monogram, and lockup, exported in SVG, PDF, EPS, and PNG, in black, white, and any approved colour variant.

**Does not hold** — construction drawings, explorations, or rejected directions. Those stay in `design-system/symbols` where their reasoning lives.

**Rule** — nothing enters this folder before final approval. A file here is one that can be sent to a printer, a journalist, or a partner without further review, and it should be treated as though it will be.

**Naming** — `sharnay-mark-primary-black.svg` · `sharnay-monogram-white.eps` · `sharnay-lockup-horizontal-black.pdf`

Every mark ships as a complete set. Partial exports are how the wrong file ends up on a banner.
