# Exports

Finished deliverables, in the form they are handed over.

Opens in **Phase 3**, with the first guidelines release. Currently empty.

---

**Holds** — dated, versioned deliverables ready to leave the studio: guidelines documents, presentation decks, press-ready print artwork, icon sets, template packs.

**Does not hold** — working files, drafts, or anything still under review.

**Rule** — an export is a snapshot, not a living file. Once a version is exported and sent, it is not edited. A change produces a new dated export, and the previous one moves to `/archive` so that there is always a record of what the client was actually given.

**Naming** — deliverable, then ISO date:

```
sharnay-brand-guidelines-2026-08-14.pdf
sharnay-icon-set-2026-08-14.zip
sharnay-print-artwork-business-card-2026-10-01.pdf
```

**Print exports** carry their specification in an accompanying note: stock, weight, finish, colour profile, bleed, and tolerance. Artwork sent without specification is artwork the printer will interpret.
