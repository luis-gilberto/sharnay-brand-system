# Photography

The working image library — the pictures this system is designed to hold.

Opens in **Phase 1**, as soon as a selection is available. Currently empty.

---

**Holds** — a selected, prepared set of Sharnay's work, organized by series. Each image at a size suitable for design work, with a note recording its series, date, and intended use.

**Does not hold** — the client's full archive, raw files, or unedited work. This is a working selection, not a backup.

**Why it matters early** — every layout, grid, and template in this project is tested against real photographs. Placeholder images hide every problem a system has and reveal none of them, and a gallery's pacing cannot be designed against pictures that do not exist.

**Rule** — nothing in this folder is retouched, cropped, or colour-adjusted by the studio. If an image needs to be different, that is a conversation with the photographer, not an edit.

**Naming** — `series-name/2026-04-portrait-01.jpg`, with the series folder carrying a short `README.md` describing the body of work.

Rights and usage permissions are confirmed before an image is used in any public deliverable.
