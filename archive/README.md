# Archive

Superseded work, kept with the reasoning that replaced it.

---

Nothing in this project is deleted and nothing is overwritten. Work that is no longer current moves here, and it arrives with a note.

This is not sentimentality. Rejected directions are the strongest available evidence for why the current direction is right, and they prevent the same ground being re-covered in six months by someone — including us — who has forgotten why the obvious idea was not taken.

---

## How it works

Archived work is filed by phase, then by system:

```
archive/
├── phase-02-visual-language/
│   ├── symbols/
│   └── typography/
└── phase-04-website/
```

Each archived item sits beside a short note recording three things: what it was, what replaced it, and why. A file with no note is only clutter.

```
mark-primary-v02.svg
mark-primary-v02.md      ← what it was, what replaced it, why
```

## What belongs here

Superseded versions of approved work. Rejected directions from a closed phase. Exports that have been replaced by a newer dated release.

## What does not

Work in progress — that stays with its system until the phase closes. Duplicates kept "just in case". Files renamed `-old` or `-final` in place of being archived properly.
