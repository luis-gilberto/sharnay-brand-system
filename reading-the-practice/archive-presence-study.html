Reading the scale

A · Document

Gained: Soft return. Private note energy.

Lost: Authority. The room outweighs the words.

Returned? Yes. Exhibited? No.

B · Threshold

Gained: The sentence holds without performing.

Lost: A little hush. Almost nothing else.

Returned? Yes. Exhibited? Not yet.

Dignity / recognition: Both peak for Archive here — or just after, toward C.

C · Artwork

Gained: First moment the words feel like an object, not a note. Short measure forces the line to breathe as form.

Lost: Some return intimacy. Still a leaf, but the leaf is now a carrier of presence.

Returned? Borderline — yes if you still feel handed-back. Exhibited? Emerging.

D · Monument

Gained: Monumental presence. The sentence occupies the page like a carved fragment.

Lost: Return. This is no longer “your words came back.” It is “look at this line.”

Returned? No. Exhibited? Yes — Exhibition territory while still on one pale leaf.

E · Breaking

Gained: Pure display force. Poster / wall-label energy.

Lost: Archive entirely. Custody becomes spectacle.

Returned? No. Exhibited? Completely. Useful only as the red line.

Hard rule before beauty

Her words must be fully readable. No cropping at the leaf edge. No hyphenation games. No “design crop.” If presence requires cutting the sentence, presence has gone too far — that setting belongs to Exhibition, not Archive.

So the system is: length tier → max presence that still fits every character. Character caps protect the leaf; type recipes protect the reading.

Where the crossing actually is

Artwork-presence is real around C when the line is short enough to fit. D/E are pressure tests — useful to see the cliff, illegal to ship if reading breaks.

Length is the other half: short → more presence, medium → moderated, long → manuscript. Always: complete sentence on the leaf.

Character counts · proposed lock

Today Archive only accepts fragments ≤ 180 chars (filter, not field UX). To make the leaf a work, the source questions need a visible ceiling:

Short band · ideal Archive line · max 48
Medium band · still one breath · max 96
Hard ceiling for Archive-eligible answers · max 140

Anything above 140 can still be answered in the intake if needed, but it should not enter the Return Plate — or it enters only as manuscript (long tier), never as monument.
