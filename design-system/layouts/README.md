# Layouts

**Grids built from photographic proportions, not from web convention.**

Opens in **Phase 2**. Currently empty.

---

## What lives here

- Grid drawings for print and screen, including behaviour at each breakpoint
- Margin logic and the spacing scale
- Supported aspect ratios and how each sits in the grid
- The three layout registers — full bleed, framed, contact sheet — and when each is used
- Composition studies applying the grid to real work
- Sequencing guidance: how a body of work is paced across pages or screens

## What does not

Page designs for a specific surface — those belong to `/website`, `/social`, or `/print`. Layouts built around placeholder images, which hide every problem a grid has.

## Standards

The grid is derived from the aspect ratios Sharnay actually shoots, so images sit as though the page were made for them. A grid that fights the work produces awkward crops forever.

Margins are specified, not eyeballed, and they are the last thing to be reduced when space is tight. Content is cut before margins are.

Every grid is documented as a drawing with dimensions, not as a list of values in a design file that only one person can open.
