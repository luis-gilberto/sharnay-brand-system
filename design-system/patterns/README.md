# Patterns

**Repeatable surface systems** — for the places a brand needs to cover an area without saying anything.

Opens in **Phase 2**, only if justified. Currently empty.

---

## What lives here

- Pattern constructions derived from the aperture geometry
- Scale and repeat rules for each intended surface
- Application guidance: where a pattern may appear and where it may not
- Production notes for print surfaces — packaging, sleeves, endpapers

## What does not

Textures. Backgrounds added to fill space. Anything not built from the system's own geometry.

## A note on necessity

This folder may stay empty, and that would be an acceptable outcome.

Patterns are useful for physical surfaces — the inside of a sleeve, the reverse of a card, packaging — where a plain surface would feel unfinished in the hand. They are rarely useful on screen, where they compete with photography for exactly the attention the photography needs.

If a pattern is developed, it will be because a specific piece required one, and it will be derived from the aperture construction rather than drawn independently. A pattern invented because the brand "needs" one is decoration, and decoration is outside this system by definition.
