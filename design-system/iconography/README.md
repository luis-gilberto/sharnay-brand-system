# Iconography

**One family. One grid. One stroke.**

Opens in **Phase 2**. Currently empty.

---

## What lives here

- The construction grid: keyline box, live area, padding, permitted angles
- Stroke weight, terminal treatment, joins, corner radii, occlusion gap
- The icon family, as source drawings
- Optical correction notes — the documented exceptions and their justification
- A specimen sheet showing the full set at every intended size

## What does not

Icons drawn for a single piece and never adopted into the family. Third-party icon sets. Illustration. Any mark that could not be rebuilt from the grid.

## Standards

Every icon uses only angles from the aperture's rotational set and arcs from a shared radius family. Detail is reduced until further reduction would break recognition, then stopped.

Icons are drawn in batches and reviewed as a set at a single size. If one stands out, that one is redrawn — not the set adjusted around it.

Depth is expressed only through occlusion. No shadows, no fills implying volume, no gradients, no perspective.
