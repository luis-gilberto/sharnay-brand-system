# Typography

**The voice, and the scale it speaks at.**

Opens in **Phase 2**. Currently empty.

---

## What lives here

- Selected families, with the licences that cover print, web, and client use
- The type scale, and the ratio it is built on
- Weight, style, and italic usage rules
- Numeral handling — tabular figures wherever numbers are data
- Measure, leading, tracking, and optical size guidance
- Specimens set as real pages, not sample sheets
- The selection rationale, including families considered and rejected

## What does not

Fonts used without a licence covering every intended medium. Decorative or display faces used for a single piece. Web font files for the site build — those are handled in `/website`.

Font binaries themselves live in `typography/fonts/` and are not committed. Licences rarely permit redistribution, and a repository is redistribution. The licence record and the source of each family are documented here in text so anyone can obtain them legitimately.

## Selection criteria

A display voice with a genuine italic, not a slanted roman. A text face with tabular numerals, since frame numbers, f-stops, dates, dimensions, and prices all appear as data in this system. Both must hold at caption size in print and at heading size on a screen, and both must be licensable for the client to use directly after handover.

Type is judged in a live specimen — a real spread with real captions and a real headline — never on a specimen sheet.
