# Color

**Colour as exposure, not as decoration.**

Opens in **Phase 2**. Currently empty.

---

## What lives here

- The palette: paper, ink, and the mid-tones between them
- At most one accent, with the reason it exists written down
- Application ratios — how much of a surface each value may occupy
- Values specified for every medium: screen, coated, uncoated, and any spot equivalent
- Contrast pairings that meet accessibility floors, verified rather than assumed
- Rules for colour over photography

## What does not

Colours sampled from individual photographs. Palettes that only exist on screen. Secondary and tertiary ranges added for flexibility — flexibility is how palettes decay.

## Standards

The photography carries the colour in this brand. The system carries the structure. Grey is not filler here; it is the mid-tone, and it does the same work in a layout that it does in a print.

A palette without ratios is a palette that will be misused, so ratios are specified alongside the values and treated as equally binding.

Every value is confirmed on paper before it is approved. Screens are persuasive; paper is decisive.
