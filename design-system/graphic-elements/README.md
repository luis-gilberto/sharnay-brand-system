# Graphic Elements

**The editorial furniture.** Rules, frames, marks, and numbers — the small things that make a page feel published.

Opens in **Phase 2**. Currently empty.

---

## What lives here

- Rule weights, tied to the icon stroke rather than invented per layout
- Frame and keyline treatments, including corner and unclosed variants
- Registration, crop, and index marks
- Frame numbering and its notation format
- Caption, credit, and folio treatments
- Contact-sheet notation

## What does not

Ornament. Dividers that separate nothing. Flourishes. Any element that exists to make a layout look more designed.

## Standards

Each element must do one identifiable job: organize, identify, separate, or annotate. An element that cannot be traced to one of the six concepts in the photographer's vocabulary is decoration and does not enter the system.

These elements carry the sense that the work is catalogued. A photograph with a frame number implies a body of work behind it, and that implication is worth more than any graphic device we could invent.

Weights come from a defined family. Numerals are tabular. Captions are one size and one style — variety here reads as indecision.
